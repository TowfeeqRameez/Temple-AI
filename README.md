# Temple-AI
The temples which have their uniqueness
Abstract
This project develops an NLP-driven system that aggregates, analyzes, and generates concise descriptions of Indian temples focusing on their unique cultural features, local beliefs, and visitor experiences. We collect multilingual data from temple websites, travel guides, local news, and user-contributed content, then apply information extraction and entity linking to identify salient attributes: rituals, festivals, origin stories, miracles, visitor-propitiated outcomes (for example, traditions that a visit brings good fortune or specific life events such as visa success), accessibility, and timing. A fine-tuned multilingual large language model (LLM) synthesizes these attributes into short, factual summaries and creative “what-to-expect” narratives tailored to different audiences (pilgrims, tourists, researchers). We incorporate fact-verification modules using knowledge retrieval and cross-source consistency checks to reduce hallucinations and mark uncertain claims (local beliefs vs. verified historical facts). The system supports search-by-feature, automated content generation for temple profiles, and an explainable UI that shows extracted evidence for each claimed uniqueness. Evaluation uses precision/recall for extraction, factuality metrics for generated text, and user studies measuring usefulness and cultural sensitivity. The resulting tool aims to preserve regional heritage, guide visitors with culturally contextualized expectations, and demonstrate responsible use of generative AI for culturally sensitive information dissemination.
